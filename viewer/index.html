Lazy-DaSH Viewers

Browser tools for the multi-robot task and motion planner (arXiv 2504.05552): check scenes, play back solves, compare evaluations with the paper.

Scene viewer

Render a scene in 3D, edit its JSON with live re-render or watch the file on disk, and run quick checks (schema, reach, overlaps, joint limits).

Opens resources/scenes/**/*.json (format lazydash.scene/1).

Result viewer

Play back a solve: arms and blocks over time, the arm timeline synced to the playhead, planning statistics, a gripper trace per arm.

Opens what lazydash_solve <scene> --out result.json writes.

Results browser

Evaluation curves per scene family against the paper's runs: planning time by stage, representation sizes, success, makespan, table.

Opens the JSON from runner/aggregate_results.py.
